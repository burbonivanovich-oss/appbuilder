# «ИИ Бизнес сигналы» v2 — всё для продолжения работы над роликом

Ролик о модификаторе «ИИ Бизнес сигналы» Контур.Маркета: **2:50, 1920×1080, 30 fps, 5 частей для сайта**.
Сделан заново после дизайн‑ревью первой версии (3:32, 8 октября) в Remotion (React + TypeScript): интерфейс
перерисован кодом по макетам Figma, анимация привязана к словам диктора, звук и музыка собраны скриптами.

Этот файл — точка входа. Если вы новая сессия Claude: прочитайте его целиком, затем `docs/REVIEW.md`,
`docs/PROCESS.md`, `docs/FIGMA.md` и скилл `skill/kontur-explainer-video/SKILL.md`.

## Быстрый старт в новой сессии

```bash
unzip kontur-signals-v2-handoff.zip && cd kontur-signals-v2-handoff/project/kontur-market-video
npm ci                                   # Remotion 4.0.290, React 18; Node 18+ (проверено на 22)
pip install faster-whisper numpy scipy soundfile pyloudnorm python-docx   # нужно только для звука, таймлайна, docx
# ffmpeg — для финальной сборки (громкость, части)

npx tsc -p .                             # проверка типов
node scripts/stills.mjs SignalsV2 out/check 2s 30s 60s 100s 150s   # стоп‑кадры → out/check/sheet.html
npx remotion studio                      # превью (если есть браузер), папка SignalsV2
python3 scripts/signals-v2-finish.py --force   # полный рендер + части + громкость → out/signals-v2 (~10–15 мин)
```

- Remotion при первом рендере скачивает свой headless Chrome. Если сеть не пускает — укажите готовый:
  `REMOTION_CHROME=/путь/к/chrome node scripts/stills.mjs …` (в облачных сессиях Claude Chromium лежит в `/opt/pw-browsers`).
- Шрифт Lab Grotesque уже встроен в `src/fontData.ts` (в git его нет, он в `.gitignore`; скачивается `npm run fetch-fonts`).
- Распознавание речи (faster-whisper) нужно, только если меняется голос: слова уже распознаны в `src/signals-v2/asr.json`.
- Новая озвучка Gemini TTS требует ключ OpenRouter (`OPENROUTER_API_KEY` или `~/.config/openrouter.key`). В архиве ключа нет.
- Скиллы: скопируйте `skill/*` в `.claude/skills/` репозитория, в котором работаете (в `project/` они уже лежат там).

## Состояние на 29.10.2026 — честно

Готово: полная версия 2:50, версия без музыки, 5 частей, главы и субтитры, обложка, сценарий v2, текст диктора
с таймкодами, раскадровка, пакет ассетов по слоям. Два прохода по ревью (подробно — `docs/REVIEW.md`).

Не сделано или не проверено:
1. **Ролик не просмотрен в движении.** Я проверял его только стоп‑кадрами (каждые 3,5 с и по 2–4 кадра на сцену).
   Ритм, плавность и звук никто, кроме людей, не оценивал.
2. **Фреймы гайда «Скринкаст» и «Графика»** (страница «Автопрезентации») я не видел глазами — кончился лимит Figma MCP
   для места View. Правила прочитаны из текста фреймов. Через Chrome их можно открыть и сравнить.
3. **Сцены «Данных достаточно», «Причины ищут вручную», «Как устроен сигнал»** во втором проходе почти не менялись.
4. **Музыка синтезирована кодом** (`scripts/signals-v2-music.py`); ревьюер назвал прошлую «очень плохой». Надёжнее
   лицензионный трек: заменить `public/signals-v2/music.wav`, приглушение под голос уже в коде.
5. **Голос синтетический** (Gemini TTS, голос Kore). Для сайта ревьюер просит человека: текст и имена файлов —
   в `texts/Текст_диктора_ИИ_Бизнес_сигналы.docx`, анимация подстроится под новые длины.
6. **Экраны перерисованы по макетам «Цифровой опердир»** (тестовые данные): нужно ревью продуктового дизайнера.
   Цифры (−12%, 23 080 ₽, 98 товаров, 15 ₽, 22 000 ₽, скидка 32%) — подтвердить у маркетинга и юристов.
7. **Скрипт After Effects** в `assets/08_ae` не запускался в AE.

## Что я бы делал дальше (по убыванию пользы)

1. Посмотреть ролик целиком и записать замечания по таймкодам — это главный пробел.
2. Через Chrome открыть в Figma фреймы гайда «Скринкаст», «Графика», «Шаблоны», «Части ролика», «Обложки»
   и сравнить с кадрами `assets/00_storyboard/frames` — список ссылок в `docs/FIGMA.md`.
3. Открыть макеты «Цифровой опердир» и сверить перерисованные экраны (размеры, цвета, тексты, иконки) —
   код экранов в `src/signals-v2/market-ui.tsx` и сценах.
4. Переделать три непеределанные сцены первой главы так же, как модули: интерфейс + вынос главного (`Lift`).
5. Заменить музыку на трек и голос на диктора, пересобрать `signals-v2-build.py` → `signals-v2-finish.py`.
