# Как сделать ролик по сценарию: пошаговая инструкция для новичков

Эта инструкция показывает, как из текстового сценария (Word) получить готовое видео с озвучкой,
анимированной графикой и макетами интерфейса. Пример — ролик «ИИ Бизнес сигналы» (`src/signals`).

## Что понадобится

| Что | Зачем | Как получить |
|---|---|---|
| Node.js 18+ | запускает Remotion (движок видео) | nodejs.org, версия LTS |
| Python 3.10+ | озвучка и распознавание речи | python.org |
| Ключ OpenRouter | доступ к голосовой модели Gemini TTS | openrouter.ai → Keys; пополнить баланс на $1–5 |
| Этот репозиторий | шаблоны сцен и скрипты | `git clone`, папка `kontur-market-video` |

Сколько стоит: озвучка 3,5-минутного ролика стоит около $0,03–0,05 в OpenRouter.

## Шаг 0. Установка (один раз)

```bash
cd kontur-market-video
npm install                 # Remotion и зависимости
npm run fetch-fonts         # фирменный шрифт Lab Grotesque
pip install faster-whisper  # распознавание речи для синхронизации
```

Сохраните ключ OpenRouter в файл, а не в код:

```bash
mkdir -p ~/.config && printf '%s' 'sk-or-v1-ВАШ_КЛЮЧ' > ~/.config/openrouter.key && chmod 600 ~/.config/openrouter.key
```

Ключ нельзя коммитить в git и пересылать в чатах. Если ключ «засветился», отзовите его в OpenRouter и создайте новый.

## Шаг 1. Превратите сценарий в JSON

Откройте `src/signals/scenario.json` как образец. Для каждой сцены сценария заполните:

- `id` — короткое латинское имя сцены (`audit`, `fines`);
- `say` — текст диктора ровно так, как он должен прозвучать. Числа пишите словами, если важно произношение («с первого сентября»);
- `cues` — 3–5 слов из текста, на которых на экране должно что-то появиться. Порядок — как они звучат.

В начале файла:

- `voice` — голос Gemini (`Kore` — спокойный женский, `Charon` — мужской; полный список в описании модели на OpenRouter);
- `instructions` — как говорить: «спокойно, уверенно, деловым тоном». Инструкция идёт отдельным полем, поэтому диктор её не произносит.

## Шаг 2. Озвучьте

```bash
python3 scripts/signals-vo.py
```

Скрипт:
1. отправляет текст каждой сцены в Gemini TTS и сохраняет `public/signals/vo/<id>.wav`;
2. распознаёт получившуюся речь и находит, на какой секунде звучит каждое слово из `cues`;
3. записывает всё в `src/signals/timing.json`.

Не понравилась одна фраза — поправьте текст и перегенерируйте только её: `python3 scripts/signals-vo.py --only audit`.

## Шаг 3. Нарисуйте сцены

Сцены лежат в `src/signals/scenes.tsx`, по одной функции на сцену. В каждой доступна функция `cue('слово')`:
она возвращает момент, когда диктор произносит это слово. Так графика всегда совпадает с голосом.

Готовые детали — в `src/signals/ui.tsx`:

| Деталь | Что делает |
|---|---|
| `Anchor` | крупный короткий текст, проявляется слева направо |
| `MarketWindow` | окно Контур.Маркета с меню и плашкой «Концепт интерфейса» |
| `SignalCard` | карточка сигнала с цветной точкой |
| `Cursor` | курсор, который едет по точкам и кликает |
| `Focus` | синяя рамка вокруг одного объекта |
| `Camera` | плавный зум на нужную часть экрана |
| `Footnote` | мелкий дисклеймер внизу |

**Если скринкастов ещё нет**, соберите экран из этих деталей: окно Маркета, таблица, кнопки, курсор.
Обязательно оставляйте плашку «Концепт интерфейса» и не показывайте функции, которых нет в продукте.
Когда появится настоящая запись, её можно вставить вместо макета через `<OffthreadVideo src={staticFile('rec.mp4')} />`.

## Шаг 4. Посмотрите и проверьте

```bash
npm run studio   # откроется редактор в браузере: выберите композицию Signals и нажмите Play
```

Что проверить:
- текст не обрезан и не наезжает на другие элементы;
- рамка и курсор указывают на правильный объект;
- дисклеймеры и сноски со звёздочкой видны достаточно долго;
- нет реальных ИНН, ФИО, цен закупки и других чувствительных данных.

## Шаг 5. Отрендерите

```bash
npx remotion render Signals out/signals.mp4
```

Трёхминутный ролик рендерится около 6 минут. Готовый файл: `out/signals.mp4`, 1920×1080, 30 кадров/с.

## Частые проблемы

| Проблема | Решение |
|---|---|
| Диктор читает инструкцию вслух | инструкция должна быть в поле `instructions`, а не в `say` |
| Ошибка 400 `response_format` | модель принимает только `pcm` или `mp3` |
| Графика появляется не вовремя | проверьте, что слово из `cues` действительно есть в `say` и стоит в правильном порядке |
| «cue estimated» в выводе скрипта | распознавание не нашло слово; время оценено приблизительно — выберите другое слово-якорь |
| Шрифт стандартный, не Контуровский | запустите `npm run fetch-fonts` |

## Если работаете через Claude Code

В репозитории есть скилл `.claude/skills/kontur-explainer-video`. Достаточно написать:
«Сделай ролик по этому сценарию» и приложить файл — Claude пройдёт все шаги сам.
