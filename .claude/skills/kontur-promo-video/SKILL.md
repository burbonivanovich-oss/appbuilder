# Короткий коммерческий ролик (15–45 с)

Проект: `kontur-market-video/` (Remotion 4 + React + TS). Эталоны:
- `src/kit/Kit.tsx` — «Комплект собирается сам» (25 с, одна сцена, камера по ключам, стиль текущего сайта) — **лучший пример**;
- `src/journey/Journey.tsx` — «Путь пакета молока» (30 с, «бесконечный зум» между сценами);
- `src/vertical/Vertical.tsx` — вертикальный 9:16 под бит, параметры через zod.

Порядок ниже выстрадан на фидбеке заказчика — не пропускать шаги 1 и 2.

## 1. Исследовать бренд по ЖИВОМУ сайту (не по памяти, не только по HTML)

Главные ошибки прошлых итераций: выдуманные цвета («Маркет оранжевый» — нет, голубой) и «стиль старого Контура».
- Смотреть не только главную, но и сегментные страницы: `kontur.ru/market/capabilities/roznitsa`, `/capabilities/obshepit`, `/capabilities/uslugi`, `/market/kkt`, `/market/kits`, `kontur.ru/ofd`.
- Делать настоящие скриншоты в Chromium, а не парсить HTML. В облачной среде TLS идёт через прокси — Chrome доверяет его CA по SPKI:
  ```bash
  python3 - <<'EOF' > /tmp/spki.txt   # хэши SPKI всех CA из бандла прокси
  import re,subprocess,base64,hashlib
  b=open('/root/.ccr/ca-bundle.crt').read()
  out=[]
  for c in re.findall(r'-----BEGIN CERTIFICATE-----.*?-----END CERTIFICATE-----',b,re.S):
      pub=subprocess.run(['openssl','x509','-pubkey','-noout'],input=c.encode(),capture_output=True).stdout
      der=subprocess.run(['openssl','pkey','-pubin','-outform','der'],input=pub,capture_output=True).stdout
      out.append(base64.b64encode(hashlib.sha256(der).digest()).decode())
  print(','.join(out))
  EOF
  B=$(find /opt/pw-browsers -name chrome -type f | head -1)
  $B --headless --no-sandbox --proxy-server="$HTTPS_PROXY" --ignore-certificate-errors-spki-list=$(cat /tmp/spki.txt) \
     --hide-scrollbars --window-size=1440,5000 --virtual-time-budget=20000 --screenshot=page.png https://kontur.ru/market
  ```
- Ассеты брать с сайта: логотипы `s.kontur.ru/common-v2/logos/logo-<product>-32.svg`, иконки продуктов `s.kontur.ru/common-v2/icons-products/<product>/<product>-24.svg`, UI-иконки `s.kontur.ru/common-v2/icons-ui/black/<name>/<name>-24-regular.svg`, фото касс `kontur.ru/Files/userfiles/image/products/market/kkt/*.png` (прозрачный фон), экраны ОФД `.../products/ofd/*.png`, студийные фото `.../market/main/bg_*.jpg`. Складывать в `public/` (в ролик) и `refs/` (референсы).
- Актуальный визуальный язык Маркета (сентябрь 2026): **студийная предметка «тёмно‑синяя стена `#12163A→#1D2352` + светлый стол `#DCD9D5`»**, белые жирные заголовки на синем, плоские плитки `#F4F5F7` с радиусом 32–48 без теней, пилюли‑кнопки и сегмент‑переключатели, тонкая стрелка ↗, синие галочки в списках. Акцент `#2291FF`, иконки продуктов `#51ADFF`, текст `#222`. Шрифт Lab Grotesque (`npm run fetch-fonts`).
- **Не делать** (это читается как «старый Контур»/шаблон): чертёжные сетки, моноширинные подписи, тени и обводки у плашек, счётчики «01 / 05», неоновые градиенты, эмодзи.

## 2. Сначала 3–4 раскадровки, потом код

Пользователь прямо просил: «собери инфу, референсы, и сделай 3–4 раскадровки сначала». Каждая концепция — со своей механикой, а не вариации одного:
- «Одна линия через весь день» (лайфстайл, фирменная голубая линия связывает сцены);
- «Путь одного чека/товара» (непрерывный пролёт камеры, 2.5D);
- «Было / стало» (сплит‑скрин под бит, для соцсетей 9:16);
- «Продукт собирается сам» (детали защёлкиваются на сцене, выноски — выбран заказчиком).

Раскадровка = HTML‑страница (Artifact) с 5–6 кадрами на концепцию, собранными из настоящих фото/экранов бренда: таймкод, действие, движение камеры, текст диктора, «сильная сторона / что нужно / сложность в Remotion». Пример структуры — последний storyboard в истории проекта. Спросить, какую концепцию собирать.

## 3. Драматургия 15–45 секунд

- 0–3 с — крючок: вопрос/боль клиента («Что нужно, чтобы открыться?»), без логотипа.
- Середина — 3–5 «битов» ценности, по одному на 3–5 с; каждый бит = одно действие на экране + короткий якорь текста (не расшифровка диктора).
- Финал 4–6 с — логотип, одна фраза‑обещание, одна CTA‑пилюля (+ второстепенная «Тарифы»), адрес сайта.
- Формулировки только с сайта или согласованные: «Кассы, учёт и госсистемы без лишней рутины», «Законодательство без тревог», «Попробовать бесплатно». Цифры (сроки ФН, цены, «1 день») помечать «проверить».

## 4. Сборка в Remotion

- Файлы: `src/<name>/<Name>.tsx`, `src/<name>/timeline.json` (кадры всех событий — общий источник для анимации и звука), регистрация в `src/Root.tsx` (`Composition` + варианты через `defaultProps`).
- Приёмы, которые заказчику понравились:
  - **одна непрерывная сцена + камера по ключевым кадрам** (`CAM = {f, s, x, y}` + `interpolate` c `Easing.bezier(0.65,0,0.35,1)`) вместо слайдов;
  - детали падают на стол со `spring` (damping 11–14) и контактной тенью, которая растёт при приземлении;
  - подписи‑выноски: `evolvePath` для линии + текст, появляющийся после неё; подписи текущего шага гаснут на следующем;
  - потоки данных — пунктир с бегущим `strokeDashoffset`;
  - финал «сцена сворачивается в карточку сайта» (`clipPath: inset(... round r)` + уменьшение), справа блок в стиле страницы.
- Вертикаль 9:16 и квадрат 1:1 — отдельные композиции того же компонента с другой раскладкой (параметры через zod‑схему, см. `Vertical.tsx`).

## 5. Звук

- Музыка и SFX генерируются кодом, синхронно с `timeline.json` (без лицензий): `scripts/make-kit-audio.mjs` — пэд + мягкий пульс + щелчки на событиях. Щелчки делать мягкими: плавная атака (`Math.min(1, x*400)`), ФНЧ на шум, тихо — заказчик просил «помягче и потише».
- Озвучка (если нужна): Gemini TTS через OpenRouter — `POST https://openrouter.ai/api/v1/audio/speech`, `model: google/gemini-3.8-flash-lite-tts`, `response_format: "pcm"` (24 kHz mono), тон — ТОЛЬКО в поле `instructions` (в `input` модель прочитает его вслух). Ключ — `OPENROUTER_API_KEY` или `~/.config/openrouter.key`, никогда не в git. Офлайн‑запасной вариант — Silero (`scripts/make-vo.py`), звучит синтетичнее.
- Реплики диктора короткие (1,5–2,5 с) и привязаны к битам; музыку приглушать под голосом (`volume` как функция кадра, ~0.35).

## 6. Проверка перед отправкой

- `npx tsc -p .`
- Контакт‑лист кадров: `npx remotion still <Id> out/k<N>.png --frame=N --scale=0.5` по 1–2 кадра на бит, склеить в HTML‑сетку и снять одним скриншотом Chromium; смотреть: текст не обрезан у краёв (особенно при наезде камеры), подписи не наезжают на предметы, всё в «безопасной зоне».
- Рендер `npx remotion render <Id> out/<name>.mp4`, контрольный кадр из готового mp4: `npx remotion ffmpeg -ss <t> -i out/x.mp4 -frames:v 1 out/check.png` (у встроенного ffmpeg нет фильтров `fps/hstack` — кадры извлекать по одному через `-ss`).
- Отправить mp4 пользователю (`SendUserFile`), коротко: что сделано, что заменено/выдумано, что проверить (цифры, формулировки).

## Грабли

- Шрифт: `delayRender` + `FontFace(url)` иногда виснет при рендере → шрифт встраивается base64 в бандл (`src/fontData.ts`, генерится `npm run fetch-fonts`) и добавляется без `delayRender`.
- Хуки внутри `.map` допустимы только для массивов фиксированной длины; хук после раннего `return null` — ошибка.
- `transformOrigin` при масштабировании изображения задавать в координатах самого элемента, иначе объект уезжает за кадр.
- Не коммитить `out/`, `node_modules/`, `src/fontData.ts`, ключи.
