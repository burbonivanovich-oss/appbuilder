# Продуктовые расширения

## Принцип

Продуктовое расширение связано с основным продуктом. Подтверждённые расширения сейчас есть для «Эгиды» и «Диадока». В исходном макете они представлены знаком вместе с названием высотой 24 px; сохраняй их размеры и начертание.

Исходник названий и связей — [страница «Продуктовые расширения» в Figma](https://www.figma.com/design/JfqSnSrlA0sKDK0nJDvsTK/%E2%9A%A1%EF%B8%8F-Kontur-Logos?node-id=1193-4208). `NameID` — имя составного знака с названием: `https://s.kontur.ru/common-v2/logos/v2/{ID продукта}/extensions/{NameID}.svg`. Для тёмного фона к `NameID` добавляется `-dark`; на статике также проверены PNG-варианты `@2x`. `IconID` в справочнике указывает на самостоятельную иконку расширения; правила выбора и построения её адреса описаны в [«Иконках продуктов»](../icons/products.md#принцип). SVG каждого расширения из справочника проверены на статике.
