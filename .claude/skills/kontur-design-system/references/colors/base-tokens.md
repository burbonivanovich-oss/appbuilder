# Базовые токены

Каждый токен хранит одно цветовое значение. Один базовый токен может использоваться для нескольких назначений.

Переменные `--k-color-card-bg`, `--k-color-page-islands-bg` и `--k-color-border` используют один базовый токен `gray-96`. Переменная `--k-color-page-bg` использует `gray-100`.

Базовый токен `base-dark-gray` используется для основного текста и усиленной границы в общих переменных светлой темы. Дополнительный цвет экосистемной схемы «Контур» использует `eco-gray-36`.

Число в имени `eco-gray-N` приблизительно соответствует уровню шкалы `gray-N`. Цвета `eco-gray-N` самостоятельны и имеют собственные значения.

Токены `gray-64` и `gray-68` пока не имеют подтверждённых значений. Правила применения: [color-rules.md](color-rules.md).
