# Семантические токены (переменные)

Семантический токен задаёт назначение и ссылается на один [базовый токен](base-tokens.md). Продуктовая или экосистемная схема выбирает акцентный и дополнительный цвета, которые не зависят от темы; общие переменные действуют для всех схем. Общие переменные, акценты и пять переопределений схемы Контура имеют значения для обеих тем. Семантические цветовые переменные этой библиотеки имеют префикс `--k-color-`; базовые токены сохраняют имена без CSS-префикса.

Правила применения переменных и ассетов: [color-rules.md](color-rules.md).

## Контракт записи переменной

- `имя: базовый токен` — одно подтверждённое значение для светлой и тёмной тем. Если у такой записи нет `dark`, значение действует в обеих темах.
- `имя` с полями `light: базовый токен` и `dark: базовый токен` — значения заданы отдельно для тем. Если указан `light`, `dark` обязателен. Запись только с `light` недопустима.
- Значение переменной — имя базового токена, а не HEX. Значение HEX храни в таблице базовых токенов.
- Таблица «Общие переменные» в разделе «Значения по темам» хранит подтверждённые привязки для каждой темы отдельно. Пустая ячейка «Темная» означает, что значение для тёмной темы пока не задано; не считай светлое значение общим для обеих тем.
- Неполная строка таблицы с пустой тёмной темой содержит подтверждённое значение только для светлой темы. Это ещё не полная запись `light`/`dark` по контракту выше. Остальные таблицы раздела пока содержат только светлые значения.

## Список семантических переменных

Общие переменные перечислены в таблице «Общие переменные», продуктовые — рядом с таблицей «Продуктовые схемы». Здесь остаются экосистемные переменные. Пустая ячейка означает, что полной статической записи по контракту пока нет. Заполненная ячейка с одним базовым токеном действует в обеих темах.

### Экосистемные

| Переменная | Значение | Комментарий |
| --- | --- | --- |
| `--k-color-eco-accent-1` | `violet-normal-100` | Фиолетовый акцент |
| `--k-color-eco-accent-2` | `mint-normal-100` | Бирюзовый акцент |
| `--k-color-eco-accent-3` | `orange-normal-100` | Оранжевый акцент |
| `--k-color-eco-accent-4` | `blue-deep-normal-100` | Синий акцент |

### Переменные продуктовой схемы

Эти переменные получают значения из выбранной схемы продукта. Их значения одинаковы для светлой и тёмной тем. Пустое поле «Значение» означает отсутствие одного постоянного базового токена для всех продуктов.

| Переменная | Значение | Комментарий |
| --- | --- | --- |
| `--k-color-product-accent` | | Акцентный токен выбранной продуктовой схемы для обеих тем |
| `--k-color-product-secondary` | | Дополнительный токен выбранной продуктовой схемы для обеих тем |
