# Kontur Design System

Источник файлов ассетов — `s.kontur.ru`. Этот скилл хранит ссылки на исходные JSON-каталоги и их локальные копии. Описания, цвета и правила хранятся в Markdown; отсутствующие сведения не подменяй предположениями.

## Порядок работы

1. Для нужного типа открой его папку в `references/` и [реестр JSON-каталогов](references/sources.md). Пустой раздел означает, что сведений пока нет. Не объявляй цветовые значения универсальным брендбуком.
2. Если в реестре есть URL, проверь актуальный JSON и обнови локальную копию командой `python3 scripts/update.py`. Если сеть недоступна, используй копию и явно укажи, что её актуальность не проверена.
3. Выбирай ассет по данным каталога, а не по догадке о пути, размере, цвете или лицензии. Ссылку на конкретный файл используй только после проверки её по подтверждённому источнику. Для иконок сохраняй размер и начертание из исходного документа автора; не меняй их по своему усмотрению.
4. При получении новой подтверждённой информации добавь ссылку на JSON-каталог в [sources.md](references/sources.md) (если она есть), описание данных — в MD-файл нужного типа, правила применения переменных — в [color-rules.md](references/colors/color-rules.md). Затем запусти `python3 scripts/update.py --local-only`, чтобы обновить [единую HTML-демостраницу](assets/overview.html). При обновлении исходного JSON через `update.py` HTML тоже пересобирается.
5. Перед перекраской ассета проверь [единый контракт применения переменных](references/colors/color-rules.md).

## Типы ассетов

### Логотипы

[Правила логотипов](references/logos/logos.md). Соответствия продукта, цветовой схемы и ID логотипа хранятся в [привязке продуктов](references/colors/semantic-tokens.md#привязка-продуктов); для бренда «Контур» — в [привязке экосистемы](references/colors/semantic-tokens.md#привязка-экосистемы).

[Справочник продуктовых расширений](references/logos/product-extensions.md) связывает расширения с основными продуктами и задаёт их названия, `NameID` и `IconID`.

### Иконки продуктов

[Правила и проверенные варианты продуктовых иконок](references/icons/products.md) — основной источник для адресов, типов и размеров иконок, включая иконки расширений. [Справочник расширений](references/logos/product-extensions.md#справочник) дополняет их связями с продуктами и ID конкретных расширений.

### Интерфейсные иконки

Источник: [icons-ui.json](https://s.kontur.ru/common-v2/icons-ui/icons-ui.json). Локальная копия: [icons-ui.json](references/icons/icons-ui.json).

Правила поиска и границы сведений: [ui.md](references/icons/ui.md).

### Иллюстрации

[Объектные иллюстрации](references/illustrations/illustrations.md): каталог ID, общие цветовые схемы и проверенные размеры, форматы и варианты на примере `business-box`. [Визуализация перекраски](../kontur-design-lib-exporter/assets/object-illustration-recoloring.html) интерактивно показывает преобразование исходных цветов `red` по данным JSON-палитры.

### Визуалы

[Папка визуалов](references/visuals/visuals.md).

### Портреты

[Цветовые сочетания фона и одежды для портретов](references/portraits/portraits.md): стандартный фон, выбор продуктового или экосистемного акцента, подходящие тона одежды и четыре визуальных примера, предоставленных автором. Это отдельный источник для оформления портретов; примеры не входят в каталоги `s.kontur.ru`.

### Цвета и цветовые схемы

[Базовые токены](references/colors/base-tokens.md) хранят значения цветов, а [семантические токены](references/colors/semantic-tokens.md) — имена переменных, назначения, привязки по темам, продуктовые и экосистемные схемы. Для новых записей применяй контракт хранения из `semantic-tokens.md`; пустые значения оставляй неизвестными.

[Единая HTML-демостраница](assets/overview.html) показывает ассеты, общие переменные, схемы, базовые токены и два независимых примера применения: экосистемный и продуктовый. В примерах элементы с неподтверждённым цветом остаются видимыми и окрашиваются в кислотные сигнальные цвета; эти цвета не являются токенами дизайн-системы. Раздел иллюстраций показывает тип «Объектные» и проверенные варианты `business-box`. При изменении Markdown пересобирай страницу через `python3 scripts/update.py --local-only`.

**Единый файл правил применения цветовых переменных:** [color-rules.md](references/colors/color-rules.md). В нём описаны сборка схемы по теме, выбор акцента, переопределения Контура, правила логотипов и интерфейсных иконок, перекраска иллюстраций. Не дублируй эти правила в каталогах ассетов.
