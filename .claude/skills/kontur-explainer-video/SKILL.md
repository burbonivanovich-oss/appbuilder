# Ролик по сценарию: сценарий → озвучка → тайминги → сцены → рендер

Проект: `kontur-market-video/` (Remotion 4, React, TypeScript). Эталонная реализация — `src/signals/`
(ролик «ИИ Бизнес сигналы», 3:23). Инструкция для людей — `kontur-market-video/GUIDE.md`.

## 1. Разобрать сценарий
- `.docx` читается без библиотек: распаковать `word/document.xml`, убрать теги (см. GUIDE.md).
- Выписать для каждой сцены: текст диктора, экранный текст (короткие якоря), что показать, дисклеймеры.
- Проверить ограничения сценария: запрещённые обещания, обезличенные данные, пометка «Концепт интерфейса».

## 2. Сценарий в JSON — `src/<name>/scenario.json`
```json
{"voice": "Kore", "instructions": "Говори спокойно, уверенно, деловым тоном…",
 "scenes": [{"id": "data", "say": "Текст диктора…", "cues": ["Но", "риск"]}]}
```
- `cues` — слова, на которых должна появиться графика (по порядку их звучания).
- Числа в `say` писать так, как их надо произнести («С первого сентября»), в `cues` можно цифрами («10»).

## 3. Озвучка — `scripts/signals-vo.py` (скопировать и поменять пути под новый ролик)
- OpenRouter: `POST https://openrouter.ai/api/v1/audio/speech`,
  `{"model": "google/gemini-3.8-flash-lite-tts", "voice": "Kore", "instructions": "…", "input": "…", "response_format": "pcm"}`.
  Ответ — PCM 24 kHz, 16 bit, mono → завернуть в WAV.
- Тон задавать ТОЛЬКО полем `instructions`. Если написать инструкцию в `input`, модель прочитает её вслух.
- Ключ: переменная `OPENROUTER_API_KEY` или файл `~/.config/openrouter.key`. НИКОГДА не коммитить ключ.
- Скрипт распознаёт озвучку `faster-whisper` (`pip install faster-whisper`) с `word_timestamps=True`
  и пишет `timing.json`: старт/длительность сцены и время каждого cue. Не найденный cue оценивается по позиции в тексте.
- Перегенерировать одну сцену: `--only audit`.

## 4. Сцены — `src/<name>/scenes.tsx`, общие элементы — `src/<name>/ui.tsx`
- Каждая сцена получает `cue('слово')` → номер кадра внутри сцены и `dur`.
- Готовые блоки в `src/signals/ui.tsx`: `Anchor` (якорный текст), `Icon` (иконки Контура, перекрашенные в синий),
  `Pill`, `MarketWindow` (окно Маркета с меню и плашкой «Концепт интерфейса»), `SignalCard`, `Cursor` (курсор с кликами),
  `Focus` (рамка-подсветка одного объекта), `Camera` (зум на область), `Footnote` (дисклеймер).
- Нет скринкаста → собрать экран в коде из `MarketWindow` + таблицы/карточки, с плашкой «Концепт интерфейса»;
  подсвечивать по одному объекту (Focus/Camera), курсор — на кликах.
- Стиль «Контур Blue»: белый фон, синий `#2291FF`, текст `#1F2328`, плитки `#F4F6F8`, радиусы 20–40, шрифт Lab Grotesque
  (`npm run fetch-fonts`), иконки — `public/icons/*.svg` с `s.kontur.ru/common-v2/icons-ui/black/<name>/<name>-24-regular.svg`.

## 5. Сборка и проверка
- Композиция: `src/<name>/<Name>.tsx` (Sequence на каждую сцену + `<Audio>` озвучки и подложки), регистрация в `src/Root.tsx`.
- Подложка: `node scripts/make-bed.mjs <сек> public/<name>/bed.wav`, громкость ~0.2.
- Проверить: `npx tsc -p .`, затем стоп-кадры `npx remotion still <Id> out/f.png --frame=N --scale=0.5`
  по 1–2 кадра на сцену (смотреть на обрезку текста, наложения, позиции курсора/рамок).
- Рендер: `npx remotion render <Id> out/<name>.mp4` (3 минуты ≈ 6 минут рендера).
- Итог прислать пользователю файлом; перечислить, что заменено макетами и что нужно подтвердить.
