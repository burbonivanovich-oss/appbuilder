# Demo playbook — оператору

Как раздать приложение 5 родителям так, чтобы дойти до реального фидбэка
без зарплаты Apple Developer и без бэкенда. Полный разговорный сценарий
для интервью — в `../docs/08-demo-walkthrough.md`.

---

## Способ 1 — Web-сборка на бесплатном хостинге (рекомендую)

**Плюсы:** низкий порог — кликнул ссылку, открылась.
**Минусы:** push-уведомления заглушены, native share через `Web Share API`
(работает в Chrome iOS/Android, не работает в Safari iOS).

### Сборка

```bash
cd mobile
EXPO_OFFLINE=1 CI=1 npx expo export --platform web --output-dir dist

# expo-router оставляет <title> пустым в статическом экспорте
# (он заполняется на гидратации). Для friend-ссылки ставим дефолт,
# чтобы в табе браузера сразу читалось имя приложения.
find dist -name '*.html' -exec sed -i \
  's|<title data-rh="true"></title>|<title>Рост малыша</title><meta name="description" content="Wonder Weeks на русском — приложение для родителей малышей до 1.5 лет."/>|g' \
  {} +
```

Получим папку `mobile/dist/` ~7 МБ с готовой статикой.

### Деплой — Netlify Drop (без аккаунта, 30 секунд)

1. Открой https://app.netlify.com/drop в браузере
2. Перетащи папку `mobile/dist/` на страницу
3. Получишь URL вида `https://random-name-12345.netlify.app`
4. Эта ссылка — в Telegram участникам

URL держится "вечно" пока не удалишь, но без аккаунта — без аналитики/паролей.

### Альтернативы

- **Vercel CLI:** `cd mobile/dist && npx vercel --prod` — если есть аккаунт
- **Cloudflare Pages:** drag-and-drop через dashboard
- **GitHub Pages:** только из публичного репо — у нас приватный, поэтому пропускаем

### Как тестировать локально перед деплоем

```bash
cd mobile
npx serve@14 dist -p 8090 -n
# открой http://localhost:8090 в браузере
```

## Способ 2 — Expo Go через tunnel

**Плюсы:** настоящий нативный опыт, push работают (после grant).
**Минусы:** участник должен установить приложение Expo Go из App Store /
Play; tunnel держится только пока твой ноутбук открыт; на iOS Expo Go
ограничивает некоторые нативные API.

```bash
cd mobile
npx expo start --tunnel
```

Запоминаем `exp://...` URL или показываем QR. Участник:
1. Устанавливает Expo Go (App Store / Play)
2. На iOS — открывает камеру, наводит на QR. На Android — в Expo Go нажимает
   "Scan QR".
3. Приложение прогружается за ~30 секунд при первом заходе

**Важно:** тоннель работает только пока ноутбук с `expo start` запущен. Для
"оставлю на день" — деплой web-версии лучше.

## Демо-ДР для разных состояний

Если участник без своего малыша или хочет посмотреть «а что будет потом», вот
**синтетические даты рождения**, которые ставят календарь в нужную точку.
Значения проверены против движка скачков для **сегодняшней даты 2026-04-26**.
Если делаешь демо позже — пересчитай (или просто прибавь нужный сдвиг к ДР).

| Желаемое состояние | ДР (=ПДР) | Что увидит на Today |
|---|---|---|
| Pre-leap (за 3 дня до начала) | `2026-02-11` | «Скачок 3 через 3 дня» |
| Active (внутри скачка 5) | `2025-10-26` | «Скачок 5 — день 8 из ≈15» |
| Calm (между 5 и 6) | `2025-09-28` | «До следующего скачка ≈6 недель» |
| All-done (после 10-го) | `2024-08-26` | Поздравительный экран + список 10 |

Для **preterm-режима** (родился раньше срока) — в форме создания малыша
нужно поставить переключатель «родился раньше срока» и ввести **ДР раньше
ПДР**:

| Состояние | ДР | ПДР | Что увидит |
|---|---|---|---|
| Calm + preterm-бейдж | `2025-08-31` | `2025-09-28` | Скорр. возраст в шапке Today; в Calendar и leap detail — пометка «по скорр. возрасту» |

Лучший сценарий для участника — **его реальный ДР**. Синтетические нужны
если у участника нет ребёнка либо для демонстрации до/после.

## Что показать первым

Не объяснять. Дать ссылку и сказать:
> «Прототип. Дата рождения малыша — настоящая. Пройди как удобно, думай вслух.
> Я молчу.»

Если человек спрашивает «а что это» — ответить «как ты сам думаешь?» и
зафиксировать в заметках. Если интерфейс не объясняет себя без подсказок —
это баг продукта, не баг участника.

Полный сценарий + 5 поведенческих вопросов — в `../docs/08-demo-walkthrough.md`.

## Чеклист перед каждой встречей

- [ ] Web-ссылка живая (открой её сам в инкогнито за 10 минут до)
- [ ] Запасной QR Expo Go (если человек хочет «как настоящее»)
- [ ] Чистый Google Doc для заметок: имя | возраст ребёнка | триггер | пересылка | заплатил бы | заметки
- [ ] Телефон с диктофоном (с разрешением участника)
- [ ] 15 минут не отвлекаться
