# MVP-скоуп: 8 недель

Один разработчик, 4 спринта по 2 недели. AI в MVP не входит — архитектура подготовлена, но фичи в V2.

## Спринт 1 (нед 1–2) — Фундамент

- Expo setup: SDK 51, TypeScript strict, expo-router, ESLint/Prettier
- Дизайн-система: токены (цвета, spacing, typography), 2 темы (light/dark), базовые компоненты Button/Input/Card
- Auth: email + пароль, Apple Sign-In, Google Sign-In (через Supabase Auth)
- Онбординг: 3 экрана, создание профиля ребёнка (имя, ДР, ПДР для недоношенных, пол опц.)
- Навигация: таб-бар (Сегодня / Календарь / Журнал / Я)

**Выход:** пользователь логинится, создаёт одного ребёнка, видит пустой таб-бар.

## Спринт 2 (нед 3–4) — Ядро: календарь скачков

- Движок расчёта скачков от ПДР (10 скачков: 5, 8, 12, 19, 26, 37, 46, 55, 64, 75 недель ±1 неделя)
- Экран **Сегодня**: где сейчас ребёнок, до/после скачка, краткое "что происходит"
- Экран **Календарь**: визуальный таймлайн скачков (прошлые / текущий / будущие)
- **Детальный экран скачка**: описание, чек-лист симптомов, 3–5 практичных советов
- Контент по 10 скачкам на русском — писать самостоятельно по CDC + общая возрастная психология. **Не копировать Wonder Weeks**.
- Локальная БД: SQLite через Drizzle ORM или WatermelonDB

**Выход:** приложение ценно без единой записи в журнал.

## Спринт 3 (нед 5–6) — Журнал и уведомления

- Быстрый журнал: настроение ребёнка (5 смайлов), тэги симптомов, заметка, фото (1 шт)
- История журнала: лента по дням
- Push-уведомления через `expo-notifications`: за 3 дня до скачка, в день начала, при завершении
- Настройки уведомлений: on/off, тихие часы
- Экспорт журнала в PDF для педиатра

**Выход:** пользователь возвращается ежедневно, есть сигнал для retention-метрик.

## Спринт 4 (нед 7–8) — Полировка и релиз

- Совместный доступ: приглашение партнёра по ссылке (read + write, 1 ребёнок)
- Настройки: приватность (экспорт данных, удаление аккаунта — GDPR / 152-ФЗ)
- Локализация i18n: ru + en
- Онбординг-тур после первого логина (3 подсказки)
- Sentry + базовые события в PostHog
- App Store / Google Play: скриншоты, описания, privacy policy, data safety forms
- TestFlight / Internal testing билды

**Выход:** билд готов к закрытой бете.

## Что режем из MVP (backlog V2)

- AI-копилот и AI-персонализация (Sprint 9–10 отдельно)
- Полноценный трекер сна (как Huckleberry) — в MVP только mood + тэги
- Трекер кормлений / подгузников — вне скоупа ниши "скачки"
- Графики роста (вес / рост / перцентили) — медицинский риск
- Мультидети — V1 один ребёнок
- Сообщество / чат — огромный скоуп модерации
- Монетизация — paywall ставим после валидации D7 retention
- Виджеты iOS / Android — после PMF
- Apple Health / Google Fit sync
- Кастомные тэги (только предустановленные)
- Комментарии к записям партнёра
- Поиск по журналу
- Геймификация / достижения
