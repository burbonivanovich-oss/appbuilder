# Схема экранов MVP

## 1. Карта навигации

```
Root
├── Splash
├── AuthStack                    (если не залогинен)
│   ├── Onboarding 1 / 2 / 3
│   └── SignIn / SignUp
├── ChildSetupStack              (если залогинен, нет ребёнка)
│   └── CreateChildProfile
└── MainTabs                     (если залогинен, есть ребёнок)
    ├── TodayTab         → LeapDetail, QuickLog
    ├── CalendarTab      → LeapDetail
    ├── JournalTab       → JournalEntry (view/edit), JournalEntryCreate
    └── MeTab            → ChildProfile, Settings, InvitePartner, Export, About

Модальные стэки (над MainTabs):
    ├── LeapDetail
    ├── JournalEntryCreate / Edit
    ├── ChildProfileEdit
    ├── InvitePartner
    ├── Paywall (заготовка, выключен)
    └── Settings/* (Notifications, Privacy, Language, About)

Deep links:
    /invite/:token      → AcceptInvite (через Auth при необходимости)
    /leap/:number       → LeapDetail (для push-уведомлений)
```

## 2. Ключевые пользовательские флоу

### F1. Первый запуск → рабочее состояние (критичный путь)

```
Splash (1.5s макс)
 → Onboarding 1: "Что такое скачки роста" (пропуск доступен)
 → Onboarding 2: "Как мы помогаем"
 → Onboarding 3: "Приватность и безопасность данных"
 → SignUp / SignIn
 → [верификация email → авто-возврат]
 → CreateChildProfile (имя, ДР, ПДР если недоношенный)
 → TodayTab с coachmarks (3 подсказки, skip доступен)
```

**KPI:** 80%+ доходят до TodayTab. Отвал на авторизации — главный риск.

### F2. Ежедневный возврат

```
Splash → TodayTab (если в active leap → баннер)
 → тап на мoод → Quick Journal Entry (1 экран, 10 сек)
 → возврат на Today, entry появился в ленте
```

### F3. Изучение скачка

```
TodayTab hero card → LeapDetail
 → просмотр "что происходит" / "симптомы" / "советы"
 → кнопка "Отметить симптомы" → JournalEntryCreate с предзаполненными тэгами
```

### F4. Приглашение партнёра

```
MeTab → "Пригласить партнёра" → выбор прав (просмотр / просмотр + запись)
 → сгенерировать ссылку → native share-sheet
 → партнёр получает ссылку → открывает → AuthStack (если надо) → AcceptInvite
 → оба видят общего ребёнка, записи синхронизируются
```

### F5. Push → детали скачка

```
Push "Скачок 4 может начаться сегодня"
 → тап → deep link /leap/4 → LeapDetail
 → если приложение не запущено — Splash → LeapDetail напрямую (пропуск TodayTab)
```

### F6. Экспорт для педиатра

```
MeTab → Export → выбор диапазона дат (пресеты: 7 дней / 30 / всё время)
 → выбор формата (PDF / JSON)
 → генерация (loading) → native share-sheet (AirDrop, email, WhatsApp, Telegram)
```

### F7. Удаление аккаунта (GDPR / 152-ФЗ)

```
MeTab → Settings → Privacy → "Удалить аккаунт"
 → предупреждение + список что удалится
 → ввод email для подтверждения
 → "Скачать копию данных перед удалением?" (опц.)
 → финальное подтверждение → sign-out → AuthStack
```

## 3. Детальные спеки экранов

### S1. Splash

- **Цель:** загрузить auth-state и сессию, решить куда роутить
- **Элементы:** логотип, никаких кнопок
- **Длительность:** макс 1.5 сек, fallback на Onboarding1 если что-то падает
- **Логика:** если token валиден и есть ребёнок → TodayTab; если token валиден без ребёнка → CreateChildProfile; иначе → Onboarding1

### S2. Onboarding 1 / 2 / 3

- **Цель:** объяснить ценность (value prop), не утомить
- **Элементы:** иллюстрация (top 60%), заголовок, 2 строки описания, dots indicator, "Далее", "Пропустить" (top-right)
- **Содержание:**
  - `1` — Ценность: "Понимайте поведение ребёнка" — иллюстрация плачущего малыша превращающегося в спокойного
  - `2` — Как работает: "Календарь из 10 скачков + журнал"
  - `3` — Доверие: "Ваши данные зашифрованы и не продаются. Это не замена педиатра"
- **Действия:** swipe между экранами, "Продолжить" на 3-м → SignUp
- **Правило:** не больше 6 секунд чтения на экран

### S3. SignIn / SignUp (один экран, toggle)

- **Элементы:** Apple Sign-In (top), Google Sign-In, разделитель "или", email input, password input, кнопка "Войти" / "Создать аккаунт", переключатель sign-in ↔ sign-up, ссылка "Забыли пароль?"
- **Валидация:** email по regex, password ≥ 8 символов, показываем требования inline
- **Ошибки:** inline под полем (не тост)
- **Важно:** Apple Sign-In первым — Apple требует для iOS review

### S4. CreateChildProfile

- **Цель:** минимум трения, получить ДР для расчёта скачков
- **Элементы:**
  - Заголовок: "Расскажите о малыше"
  - Имя (опц., можно "Малыш")
  - Дата рождения (date picker, обязательно)
  - Toggle "Родился раньше срока" → раскрывается поле "Предполагаемая дата родов (ПДР)"
  - Пол (опц., три варианта: мальчик / девочка / пропустить)
  - Фото (опц., позже)
  - Кнопка "Готово"
- **Важно:** сразу объясняем зачем ПДР: "Для недоношенных скачки считаем от ПДР, так точнее"
- **Валидация:** ДР не раньше 5 лет назад, не в будущем
- **По нажатию "Готово":** создаётся запись, считаются все 10 скачков, next push планируется → TodayTab

### S5. TodayTab (главный экран)

- **Верх:**
  - Header: аватар ребёнка + имя + возраст ("Лёва, 14 недель"). Тап → ChildProfileView
  - Справа — иконка уведомлений (если непрочитанные — бейдж)
- **Hero-карточка (варианты):**
  - Active leap: "Скачок 3 — день 2 из ~7", прогресс-бар, краткое описание, CTA "Подробнее"
  - Pre-leap: "Скачок 4 ожидается через 3 дня"
  - Calm period: "Спокойный период. До следующего скачка ~12 недель"
  - Uncertain: "Возможно начался скачок 4. Отметьте симптомы" (±3 дня окно)
- **Быстрый журнал:** "Как сегодня?" + 5 эмодзи (😊 😐 😢 😫 😴). Тап → QuickJournalEntry (создаёт запись за 1 тап, можно отредактировать)
- **Недавние записи:** горизонтальный скролл 3 последних карточек. CTA "Все записи" → JournalTab
- **Pull-to-refresh:** синхронизирует данные партнёра
- **Empty state:** если журнал пуст — "Начните с первой записи. Это займёт 10 секунд"

### S6. CalendarTab

- **Цель:** визуально показать все 10 скачков в одном месте
- **Элементы:**
  - Вертикальный таймлайн от 0 до ~80 недель
  - Маркеры скачков: круги с номерами 1–10
  - Текущий момент — горизонтальная линия "Сейчас"
  - Состояния скачков: прошедший (серый), активный (цветной с пульсацией), будущий (outlined)
  - Под каждым маркером: недели (5w, 8w, 12w, 19w, 26w, 37w, 46w, 55w, 64w, 75w)
- **Взаимодействие:** тап на скачок → LeapDetail; pinch-to-zoom для детализации (nice-to-have)
- **Альтернативный вид:** toggle "Список" вверху — плоский список скачков с датами (для тех кому таймлайн непонятен)

### S7. LeapDetail

- **Структура:** scrollview с секциями
  - Header: "Скачок 3 · Плавные переходы"
  - Мета: "Возраст ~12 недель · длится 1–3 недели"
  - Статус-пилюля: "Идёт прямо сейчас" / "Ожидается через X" / "Прошёл X назад"
  - **Секция 1 — Что происходит** (3–4 абзаца, простой язык, без паники)
  - **Секция 2 — Симптомы** (чек-лист, можно отмечать галочками — записывается в журнал):
    - Больше плачет
    - Хуже спит
    - Требует больше контакта
    - Отказывается от еды
    - Новые звуки / движения
  - **Секция 3 — Что делать** (3–5 практичных советов)
  - **Секция 4 — Что нового появится** (milestones после скачка)
  - CTA внизу: "Добавить запись в журнал" → JournalEntryCreate с предзаполненными симптомами
- **Важно:** тон мягкий, без "должно / обязательно". Дисклеймер внизу "Это общая информация. При тревоге — к педиатру"

### S8. JournalTab

- **Элементы:**
  - Header: "Журнал" + FAB (+) в правом нижнем углу
  - Фильтры (chip-ряд): Все / Симптомы / Вехи / С фото
  - Лента записей по дням (секции-заголовки: "Сегодня", "Вчера", "12 марта")
  - Карточка записи: дата + время, mood emoji, тэги симптомов, сниппет текста, thumbnail фото
- **Пустое состояние:** большая иллюстрация + "Записей пока нет" + CTA "Создать первую"
- **Взаимодействие:**
  - Тап на карточку → JournalEntryView
  - Свайп влево → Удалить (с undo-snackbar)
  - FAB → JournalEntryCreate

### S9. JournalEntryCreate / Edit

- **Элементы (сверху вниз):**
  - Дата / время (default сейчас, можно изменить)
  - Настроение (5 эмодзи, обязательно)
  - Тэги симптомов (chips, multi-select: плачет, не спит, требует контакта, аппетит, вехи, другое)
  - Текстовое поле "Заметка" (multiline, опц.)
  - Кнопка "Добавить фото" (1 фото в MVP, сохраняется локально + в Storage)
  - Связать со скачком (auto-detected если в активном окне, можно изменить)
- **Actions:** "Сохранить" (top-right), "Отмена" (top-left)
- **Optimistic UI:** сохраняется в SQLite мгновенно, sync в фоне; если фейл — иконка "не синхронизировано" на карточке

### S10. JournalEntryView

Read-only версия JournalEntryCreate + автор записи ("Добавил: вы / Мария") + кнопки "Редактировать" / "Удалить" (если автор — ты).

### S11. MeTab (профиль и настройки)

- **Блоки (cards):**
  - Профиль пользователя (аватар, имя, email) → EditProfile
  - **Ребёнок:** "Лёва, 14 недель" → ChildProfileView
  - **Пригласить партнёра** → InvitePartner (если партнёров нет)
  - **Партнёры:** "Мария (просмотр + запись)" → управление (если есть)
  - **Настройки:**
    - Уведомления (toggle сводный) → NotificationSettings
    - Язык → LanguageSettings
    - Приватность → PrivacySettings
  - **Поддержка:** FAQ, связаться, оставить отзыв в сторе
  - **О приложении:** версия, правовые документы, дисклеймер
  - **Выйти** (destructive, в самом низу)
  - **Премиум (заготовка):** скрыт в MVP

### S12. NotificationSettings

- **Toggle-группы:**
  - Уведомления о скачках (главный toggle)
    - За 3 дня до скачка
    - В день начала
    - В день завершения
  - Активность партнёра (новая запись)
  - Напоминания (если 3+ дня нет записей)
- **Тихие часы:** от (22:00) до (08:00) — в это время не шлём локальные
- **Тестовое уведомление:** кнопка "Отправить тест" для проверки, что доходит

### S13. PrivacySettings

- Экспорт данных (→ Export flow F6)
- Удалить аккаунт (→ F7 destructive flow)
- Политика конфиденциальности (link)
- Управление согласиями (reset и показать заново)

### S14. InvitePartner

- **Шаг 1:** выбор прав — "Только просмотр" / "Просмотр и запись" (default)
- **Шаг 2:** "Ссылка действительна 7 дней" + preview URL + кнопка "Поделиться" (native share-sheet)
- **Шаг 3 (опц.):** после отправки показываем статус "Ожидает подтверждения"
- Если ссылка уже отправлена — экран показывает "Отменить приглашение"

### S15. AcceptInvite (landing по deep-link)

- **Если не залогинен:** сначала AuthStack с return URL
- **После логина:** карточка "Мария приглашает вас к ребёнку «Лёва»" + права + кнопки "Принять" / "Отклонить"
- После accept → добавляем `child_access` row → MainTabs с этим ребёнком

### S16. Paywall (заготовка, выключен в MVP)

- Включится в V2 когда будут AI-советы
- Структура: hero + 3 benefits + price toggle (monthly / annual) + CTA + restore purchases + small print

## 4. Пустые состояния и edge cases

| Экран | Edge case | Решение |
|-------|-----------|---------|
| TodayTab | Первый запуск, нет записей | Illustration + "Начните с первой записи" |
| TodayTab | Ребёнок старше 20 мес | "Поздравляем, все скачки позади!" + CTA в V2 модуль |
| CalendarTab | Ребёнок < 1 недели | "Скоро начнётся первый скачок (5 недель)" |
| LeapDetail | Скачок далеко в будущем | Скрываем "Отметить симптомы" |
| JournalTab | Нет записей | Empty illustration + CTA |
| JournalTab | Нет интернета | Показываем локальный кэш + тост "Оффлайн-режим" |
| InvitePartner | Уже есть партнёр и премиума нет | В MVP лимит 1 партнёр — блокируем с сообщением |
| Notifications | Разрешения не даны | Баннер на TodayTab "Разрешите уведомления, чтобы не пропустить скачки" с CTA в системные настройки |
| Auth | Email не подтверждён 5 мин+ | "Не пришло письмо?" → resend + смена email |
| Deep link | Invite expired | "Ссылка устарела. Попросите новую у партнёра" |

## 5. UX-принципы

1. **Тёплый тон.** Никогда "должен / обязан". Формулировки: "может быть", "часто у детей", "попробуйте".
2. **Никогда не паниковать.** Избегаем слов "проблема", "симптомы болезни" вне контекста медицинских статей.
3. **Один primary CTA на экран.** Всё остальное — вторичные.
4. **Цифры интерпретируем.** Не "скачок 4 на 19 неделе" без пояснения, а "около 4.5 месяцев".
5. **Оффлайн — это норма.** Все flow должны работать без сети, sync — в фоне.
6. **Respect time.** Quick journal entry — 10 секунд. Новая запись с деталями — 30 секунд. Не дольше.
7. **Приватность видима.** Иконка замка, "зашифровано", "не продаём данные" — на 3 экранах минимум.
8. **Недоношенные first-class.** ПДР везде используется при расчётах, а не "костыль".
9. **Партнёр ≠ копия.** Показываем кто добавил запись, аватар автора, возможность комментариев (V2).
10. **Дисклеймер.** На LeapDetail, на онбординге, в настройках — "не замена педиатра".

## 6. Что НЕ входит в MVP экраны

- Множество детей (один slot)
- Тэги кастомные (только предустановленные)
- Комментарии к записям партнёра
- Графики / аналитика поведения
- Поиск по журналу
- Виджеты iOS / Android
- Dark mode toggle (следуем системе, отдельно не даём)
- Темы оформления
- Достижения / геймификация
