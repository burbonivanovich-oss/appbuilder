# План работы

Концепт: мобильное приложение для родителей с трекингом ментальных скачков (Wonder Weeks) 0–20 мес. Ядро продукта — календарь скачков + журнал поведения. AI в V2.

Стек: Expo SDK 51 + React Native 0.74+ + TypeScript + Supabase.

## Фазы

| Фаза | Недели | Что делаем | Выход |
|------|--------|------------|-------|
| 0. Research | 1 | Интервью 8–10 родителей, анализ WW/HB/BC, выбор ПДР-модели | Product brief + 3 JTBD |
| 1. Design | 2 | Инфо-архитектура, wireframes, дизайн-система (токены, 2 темы), контент-план скачков | Figma + контент-док |
| 2. MVP build | 3–10 | 4 спринта по 2 нед (см. `01-mvp-scope.md`) | TestFlight / Internal build |
| 3. Closed beta | 11–14 | 30–50 родителей, еженедельные правки, метрики ретеншна | Решение go / pivot |
| 4. Soft launch | 15–18 | RU store first, потом EN, платный слой включаем после D7 > 40% | Первые платящие |
| 5. Масштаб | 19+ | **Модуль 1–3 года (retention bridge)**, AI-слой, полный partner-account, мультидети, Apple Health | V2 |

## Критерии успеха MVP

- D1 retention > 60%
- D7 retention > 30%
- 20%+ пользователей создают ≥ 3 записи в журнал за первую неделю
- NPS ≥ 40 по итогам закрытой беты

Если после беты (конец недели 14) метрики не достигнуты — пивот или смена ниши. Не масштабируем до soft launch.

## Ключевые риски

1. **Научная критика Wonder Weeks** — не опираемся на брендовую терминологию, строим на CDC/WHO milestones + возрастная психология.
2. **Низкий ретеншн после 12–15 мес** — скачки заканчиваются и WW-формат теряет смысл (подтверждено интервью с Машей). В V2 **обязательный** мост в «развитие 1–3 года» (Kinedu-style). Без него юнит-экономика не сходится.
3. **Монополия WW на бренде** — дифференциация через персонализацию, русскоязычность, чистый UX без one-time paywall.
4. **Юридика** — данные ребёнка = чувствительные (GDPR Art. 8, COPPA, 152-ФЗ). Дисклеймер «не медицинское устройство» обязателен.
5. **Тревожность UX** — приложение легко превратить в источник паники. Tone of voice важнее фич (см. `06-tone-of-voice.md`).
6. **Главный конкурент — Telegram-чаты, не WW** (новый риск из интервью). WW можно обыграть через UX, чаты — нет. Стратегия: «дополняем чат, не заменяем» + позиционирование «без паники чужих мам».
7. **Pre-acquisition window** — если пользователь установит WW на 30-й неделе беременности (по совету подруги), мы её теряем. Нужен active push в pregnancy-сегмент до родов.

## Монетизация (post-MVP)

- Free: календарь скачков + 10 записей в журнал в месяц
- Premium: $3.99/мес или $29.99/год — AI-советы, безлимитный журнал, PDF-экспорт, совместный доступ с 2+ партнёрами
- Включаем paywall только после валидации D7 retention > 30%
- **Маркер из интервью:** Маша платит $5/мес за Kinedu в Краснодаре, Анна — 290 ₽/мес за «Доктор Поспелов». Готовность платить подтверждена и в столицах, и в регионах. Конкретная цена нашего продукта — валидируется на бете A/B.
